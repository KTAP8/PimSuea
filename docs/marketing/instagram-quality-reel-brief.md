# Instagram quality Reel brief (฿1k/month test)

**Goal:** intent traffic to a **citable pricing page**, not signup volume. Do not repeat Aug 12–15 “awareness burst” creatives.

## Pick one angle (match paid buyers)

1. **ของขวัญ 1 ตัว** — personal gift, ~฿298+ on screen, PromptPay, 5–14 days  
2. **ชมรม / ทีม จำนวนน้อย** — 10–40 pcs, instant quote, no LINE admin  

## Spec

- Length: 15–30s  
- On-screen text (Thai): สั่ง 1 ตัวได้ · รู้ราคาทันที · PromptPay  
- Voiceover optional; captions required  
- CTA in caption: link to **https://pimsuea.com/pricing** or **https://pimsuea.com/custom-shirt-no-minimum**  
- Do **not** link only to app register with no price context  

## Boost rules (optional ฿1,000)

- Boost only if organic Reel already has saves or DMs  
- Audience: Thailand, 18–34, interests: ของขวัญ / ชมรมมหาวิทยาลัย / เสื้อยืด (test one)  
- Kill after 7 days if signup→studio rate is worse than organic IG (check Supabase `referral_source = instagram` + PostHog `studio_opened`)  

## Script skeleton (gift)

1. Hook: “สั่งเสื้อลายเดียว ไม่มีขั้นต่ำ”  
2. Show studio: upload → live ฿ on screen  
3. PromptPay checkout mention  
4. CTA: “ดูราคาในหน้า bio” → `/pricing`  

## Script skeleton (club)

1. Hook: “ชมรม 20 ตัว รู้ราคาก่อนสั่ง”  
2. Quick mockup + total per piece  
3. จัดส่งทั่วไทย  
4. CTA: `/club-and-gift-shirts`  

## Post-publish

- Note post date + link in IG Insights  
- Compare week of signups vs prior 4-week IG average
